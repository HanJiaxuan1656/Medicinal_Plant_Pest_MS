# 药用植物病虫害管理系统 - 微信小程序

## 📱 项目简介

这是药用植物病虫害管理系统的微信小程序端，为普通用户提供便捷的移动端访问体验。用户可以通过小程序浏览药用植物信息、查看病虫害资料、获取农药信息，并向专家寻求帮助。

## 🏗️ 技术架构

### 前端技术栈
- **框架**: 微信小程序原生开发
- **样式**: WXSS + Flex布局
- **状态管理**: 页面级状态管理
- **网络请求**: wx.request 封装
- **图片处理**: 小程序原生API

### 后端对接
- **API基础地址**: `http://localhost:8080/api`
- **认证方式**: JWT Token
- **数据格式**: JSON
- **文件上传**: multipart/form-data

## 🚀 快速开始

### 环境要求
- 微信开发者工具
- Node.js 14+
- 后端服务已启动

### 安装步骤

1. **克隆项目**
   ```bash
   git clone [项目地址]
   cd miniprogram
   ```

2. **配置小程序**
   - 在微信开发者工具中导入项目
   - 修改 `app.js` 中的 `baseUrl` 为实际后端地址
   - 配置 `project.config.json` 中的 `appid`

3. **启动开发**
   - 在微信开发者工具中点击编译
   - 选择模拟器或真机预览

### 配置说明

#### API配置
在 `app.js` 中修改后端API地址：
```javascript
globalData: {
  baseUrl: 'http://your-backend-url/api'
}
```

#### 小程序配置
在 `project.config.json` 中配置小程序AppID：
```json
{
  "appid": "your-miniprogram-appid"
}
```

## 🔧 开发指南

### 新增页面
1. 在 `pages` 目录下创建页面文件夹
2. 创建 `.wxml`、`.wxss`、`.js` 文件
3. 在 `app.json` 中注册页面路径

### API调用
使用封装的请求方法：
```javascript
const app = getApp()

// GET请求
app.request({
  url: '/normal/plants',
  data: { page: 1, pageSize: 10 }
})

// POST请求
app.request({
  url: '/normal/comments',
  method: 'POST',
  data: { content: '评论内容' }
})
```

### 样式规范
- 使用 `rpx` 作为尺寸单位
- 遵循设计稿 750px 宽度标准
- 使用全局样式类减少重复代码
- 保持组件样式的独立性

### 数据管理
- 页面级状态使用 `this.setData()`
- 全局状态存储在 `app.globalData`
- 本地存储使用 `wx.setStorageSync()`
